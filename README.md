# Rift Library

A local web app that tracks where every physical Riftbound card is, and builds and takes apart decks from those locations. It is the Riftbound version of [Library of Gathering](https://github.com/qiuey00/library-of-gathering-v2).

The product and design docs are in [docs/](docs/README.md).
