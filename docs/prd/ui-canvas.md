# Rift Library: UI canvas

Oct 23, 2026 · @Jeff

Part of the [Rift Library: PRD](README.md). The [Rift Library UI screens canvas](https://claude.ai/artifact/MnTudz5VjYUWNhVAY6pEXi) draws the screens that change from Library of Gathering, in the look of the [Library of Gathering design canvas](https://claude.ai/artifact/3cPBiMTicSPBafVKLEVTSi). Screens not on it look as they do there. Where the canvas and [Rift Library: UI Design](ui-design.md) differ, the canvas wins. Status: approved by Jeff on 2026-10-23.

Each board must be approved before the screen issues that use it start (#11, #21, #22, #23). Card names, numbers and counts on the boards are stand-ins until card data comes from Riftcodex, and card images are stand-ins in each card's domain colors.
